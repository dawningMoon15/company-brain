# Company Brain

AI-powered enterprise knowledge assistant using RAG, semantic retrieval, and conversational document intelligence.

## Features
- Workspace-based document organization
- PDF upload and parsing
- Semantic search using vector embeddings
- Conversational AI chat
- Source-grounded citations
- Streaming AI responses

## Tech Stack
Frontend:
- Next.js
- TypeScript
- TailwindCSS

Backend:
- FastAPI
- PostgreSQL
- Supabase

AI:
- OpenAI API
- ChromaDB
